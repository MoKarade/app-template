# Boîte du Réacteur

Ce fichier ne sert à rien d'autre qu'à permettre une pull request brouillon permanente.
La PR « Boîte du Réacteur » est une boîte aux lettres : la routine Réacteur y dépose un commentaire
quand un événement demande le jugement du Coordinateur, et le Coordinateur, abonné à la PR,
est réveillé par chaque commentaire. Elle ne doit jamais être fusionnée ni fermée.

Règle de format d'un commentaire : une ligne qui commence par `RÉACTEUR :` puis le dépôt, le numéro, le motif.
